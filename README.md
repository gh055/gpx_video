# GPX_Video 🏔️🎥

**A modular, data-driven GPX video overlay engine built for DaVinci Resolve workflows.**

GPX_Video renders high-performance, frame-accurate telemetry graphics (speed, elevation profiles, GPS tracks, timestamps, and sensor data) directly over action camera footage or onto transparent alpha-channel video streams (`.mov` with ProRes 4444) for seamless integration with Davinci Resolve.

---

## Key Features

* **Data-Driven Architecture:** Layouts, styling, font specs, and anchoring are defined via clean TOML configuration files.
* **Chained Relative Anchoring:** Position widgets relative to parent elements—shift a map or elevation profile, and attached labels move automatically.
* **Safe AST Expression Engine:** Perform configuration-level unit conversions (e.g., $m \to km$, $m \to ft$, ${^\circ}\text{C} \to {^\circ}\text{F}$) using a secure math expression evaluator without modifying Python code.
* **Namespace-Agnostic GPX Parsing:** Extracts standard telemetry alongside nested extensions (Heart Rate, Cadence, Temperature) from GPX files.
* **Sub-Pixel Cairo Rendering:** Utilizes PyCairo for sharp vector graphics, outline-aware text alignment, and stroke padding compensation.

## Architecture Overview

```
[ GPX Track File ] ──► [ GPX Parser / Interpolator ]
                                 │
[ TOML Layout Config ] ──► [ WidgetFactory ]
                                 │
                         [ OverlayRenderer ] ──► [ PyCairo Engine ] ──► [ FFmpeg Pipe / Image Export ]

```

## Installation

### Prerequisites

Ensure you have **Python 3.10+** and **FFmpeg** installed on your system.

#### Linux (Ubuntu/Debian)

```bash
sudo apt update
sudo apt install python3-cairo-dev libcairo2-dev ffmpeg

```

#### macOS (Homebrew)

```bash
brew install cairo ffmpeg

```

---

### Setup Repository

```bash
git clone https://github.com/your-username/gpx_video.git
cd gpx_video

python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

pip install -r requirements.txt

```

## Usage

### Single Frame Preview

Render a single test frame at a specific timestamp to verify widget alignment and positioning:

```bash
python gpx_video.py --config config.toml --output testframe.png

```

### Video Render (ProRes / Alpha Channel)

Render the full overlay video stream with transparency for DaVinci Resolve:

```bash
python gpx_video.py --config config.toml

```

---

## DaVinci Resolve Workflow

1. Open Davinci Resolve and switch to a timeline which contains your action camera footage.
2. Render the overlay video from GPX_Video as a **ProRes 4444 sequence**. GPX_Video will automatically detect Davinci Resolve running in the background and fetch the media clips from the DR timeline.
3. Drag the rendered overlay clips into your DaVinci Resolve timeline on the track above your action camera footage. Each overlay clip generated by GPX_Video will have the exact same length as the underlying original clip from the footage, making alignment trivial.
